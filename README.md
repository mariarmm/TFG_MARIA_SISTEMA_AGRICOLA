**Sistema de Gestión Agrı́cola con Monitorización de Maquinaria y Asignación de
Tareas**

Trabajo Fin de Grado del Grado en Ingeniería Informática de la Universidad de Granada.

Desarrollo de un sistema de gestión agrícola formado por una aplicación web y una aplicación móvil para la planificación de tareas, gestión de trabajadores y monitorización de la ubicación de la maquinaria y el personal en tiempo real.
